# Ployl

Medizinprodukte-Management System mit Desktop-GUI. Die ausführliche Dokumentation findest du unter [`docs/medizinprodukte_management_system.md`](docs/medizinprodukte_management_system.md).

## Schnellstart

```bash
pip install -r requirements.txt
python main_app.py
```

Beim ersten Start wird automatisch ein Administrator-Account `admin` mit dem Passwort `admin` angelegt.
